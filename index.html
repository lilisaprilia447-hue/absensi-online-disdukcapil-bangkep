Pengaturan Koneksi Cloud Supabase

Hubungkan agar data antar HP/Laptop tersinkronisasi otomatis.

Langkah Mudah Menghubungkan:
1. Tutup pop-up "Snippets no longer save automatically" di Supabase dengan klik Understood.
2. Klik Salin SQL di bawah, lalu tempel dan klik Run di SQL Editor Supabase.
3. Salin Project URL dari menu Project Settings → Data API di Supabase, tempel di kolom bawah, lalu klik Simpan & Hubungkan.

Salin dari Dashboard Supabase → Project Settings → Data API → Project URL.

SQL Tabel (Jalankan sekali di SQL Editor Supabase): 
create table if not exists public.absensi_pegawai (
  id text primary key,
  name text not null,
  nip text not null,
  status text not null,
  session text not null,
  date_iso text not null,
  date_display text not null,
  photo text not null,
  timestamp_ms bigint not null
);
alter table public.absensi_pegawai enable row level security;
create policy "Akses Publik Absensi" on public.absensi_pegawai for all using (true) with check (true);
